<h1 align="center">Mirage</h1>

<p align="center">
  Другое лицо на видеозвонке. Вживую, на вашем Mac, просто по приколу.
</p>

<p align="center">
  <img src="assets/icon/mirage-256.png" alt="Иконка Mirage" width="128">

</p>

Mirage — небольшое приложение для macOS, которое подменяет лицо в реальном
времени. Выбираете фото, жмёте **Старт** — и в Zoom или Meet вы уже друг
(который не против), сгенерированный незнакомец или снова вы сами, одной
клавишей.

Это хобби-проект: более удобная, «родная» для macOS оболочка в стиле Apple
Liquid Glass поверх отличного открытого движка
[Deep-Live-Cam](https://github.com/hacksider/Deep-Live-Cam) от hacksider и
контрибьюторов. Вся тяжёлая работа (поиск лица, модель замены, улучшение
качества) — их заслуга. Mirage добавляет окно, библиотеку лиц, вывод в
виртуальную камеру и кучу исправлений стабильности.

> [!IMPORTANT]
> **Сначала согласие.** Используйте чужое лицо, только если человек не против,
> и говорите собеседникам, когда это розыгрыш. Mirage — для личного
> некоммерческого развлечения: модели лиц, на которых он работает, разрешены
> только для некоммерческого использования. Загляните в
> [правила использования](docs/RESPONSIBLE_USE.md) (там коротко; текст на
> английском).

## Что умеет

- **Одно окно в стиле Liquid Glass.** Живое превью и одна большая кнопка
  «Старт/Стоп». Боковая панель и панель управления — настоящее стекло macOS
  (`NSGlassEffectView`), в котором мягко преломляются цвета вашего же видео.
- **Библиотека лиц.** Перетащите фотографии в боковую панель — лица появятся
  большими круглыми миниатюрами. Кликните или нажмите `1`–`9`, чтобы
  переключиться мгновенно (эмбеддинги лиц закешированы, повторно ничего
  не распознаётся). `0` (плитка «Я») возвращает ваше настоящее лицо, 🎲 —
  случайное сгенерированное.
- **Простые настройки.** Режимы качества **Быстро / Баланс / Лучше** («Лучше»
  добавляет улучшение лица), «Сохранять мой рот» (ваш рот остаётся видимым,
  и речь выглядит естественно), ползунки смешивания и резкости. В разделе
  **Ещё**: «Менять всех в кадре» (выбранное лицо получают все, кто в кадре),
  «Убрать синеву», «Мягкие края» и «Показывать FPS».
- **Сделано для звонков.** Видео идёт прямо в **OBS Virtual Camera** в
  фиксированном 1280×720, поэтому Zoom не видит перезапуска потока, когда
  веб-камера меняет формат кадра. Работает со свёрнутым окном и не даёт Mac
  уснуть, пока вы в эфире.
- **Чисто запускается и закрывается.** Запускается только одна копия (повторный
  запуск просто выводит окно вперёд). При выходе камера всегда освобождается, а
  все потоки останавливаются — даже посреди звонка.
- **Настоящее приложение.** `Mirage.app` со своей иконкой, интерфейс на
  английском и русском.
- **Быстро на Apple Silicon.** Около 14 fps в эфире на MacBook Air M1. Модель
  замены работает на Apple Neural Engine (около 63 мс на кадр против примерно
  82 мс со стандартной настройкой CoreML), а поиск лица идёт на GPU в
  отдельном потоке, так что они работают одновременно. Для живого видео лицо
  ищется на картинке 320 пикселей: около 9 мс вместо 26 мс при 640.

## Что нужно

| | |
|---|---|
| macOS | Рекомендуется 14 или новее. Эффект Liquid Glass требует macOS 26+; на старых версиях будет простое тёмное окно. |
| Mac | Нужен Apple Silicon (M1 или новее); на Mac с Intel установщик остановится. |
| Диск | Около 4 ГБ свободного места (окружение Python и модели). |
| Инструменты | [Homebrew](https://brew.sh) и Xcode Command Line Tools (`xcode-select --install`). |
| Виртуальная камера | [OBS Studio](https://obsproject.com) (бесплатно). Mirage только пользуется её виртуальной камерой; сцены и источники настраивать не нужно. |

## Установка

```bash
git clone https://github.com/RebSem/mirage
cd mirage
make install
```

`make install` запускает `scripts/install.sh`: ставит Python 3.14 через
Homebrew, создаёт виртуальное окружение, скачивает модели и предлагает
установить OBS. Его можно спокойно запускать повторно: готовые шаги
пропускаются.

Режим **Лучше** добавляет улучшение лица моделью GPEN-BFR-256 (около 75 МБ).
Mirage скачает её, когда вы впервые выберете «Лучше»; чтобы скачать заранее,
выполните `scripts/install.sh --with-enhancer`. Если модель не загрузится,
Mirage вернёт качество на **Баланс** и сообщит об этом.

Дальше можно запускать Mirage прямо из папки проекта:

```bash
make run
```

или собрать полноценное приложение (`dist/Mirage.app`) и положить его в
`~/Applications`:

```bash
make app && make install-app
```

`Mirage.app` запускает код из папки, которую вы клонировали, поэтому не
перемещайте и не удаляйте её. Если всё же переместили, выполните
`make install-app` ещё раз уже из нового места.

При первом нажатии «Старт» Mirage запросит у macOS доступ к камере и дождётся
вашего ответа. Нажмите **Разрешить** (если случайно отказали, загляните в
[решение проблем](docs/TROUBLESHOOTING.md#mirage-cant-use-the-camera)). Если
виртуальная камера пока не видна в Zoom, откройте OBS один раз и один раз
нажмите **Start Virtual Camera**, чтобы установилось системное расширение
(подробности в [решении проблем](docs/TROUBLESHOOTING.md#obs-virtual-camera-is-missing)).

## Как использовать в Zoom (Meet и других)

1. Откройте Mirage и выберите лицо (или `0`, чтобы пока остаться собой).
2. Нажмите **Старт** (или `Пробел`) и дождитесь надписи «В эфире».
3. В Zoom откройте **Настройки → Видео** (*Settings → Video*) и выберите
   камеру **OBS Virtual Camera**.
   В Google Meet и других приложениях так же: выберите
   *OBS Virtual Camera* как камеру.
4. Переключайте лица прямо во время звонка клавишами `1`–`9`. `0` — снова вы.

Не нажимайте *Start Virtual Camera* в самом OBS, пока Mirage транслирует:
они начнут драться за одну и ту же камеру. Если в Zoom вместо вас логотип
OBS — значит, Mirage ещё не в эфире или кадры до камеры не доходят (подробнее
в [решении проблем](docs/TROUBLESHOOTING.md#zoom-shows-the-obs-logo-or-a-black-picture)).

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Пробел` | Старт / Стоп |
| `1` – `9` | Переключиться на лицо 1–9 |
| `0` | Ваше настоящее лицо |
| `⌘O` | Добавить фото |
| `⌘R` | Случайное лицо |
| `⌘⇧M` | Зеркалить превью (в звонке картинка никогда не зеркалится) |
| `⌘Q` | Выйти |

## Как получить правдоподобный результат

- Берите чёткое фото анфас с ровным светом, одно лицо на снимке.
- Освещайте своё лицо спереди; окно за спиной всё сильно усложняет.
- На MacBook Air подключите зарядку и начните с режима **Быстро**. У Air нет
  вентилятора, и при нагреве он замедляется.
- Если рот при разговоре выглядит «резиновым», включите «Сохранять мой рот».

Больше — в [решении проблем](docs/TROUBLESHOOTING.md).

## Ваши данные остаются на Mac

Всё видео обрабатывается локально; поток с камеры никуда не уходит. В сеть
Mirage ходит только за моделями (при установке, при первом выборе режима
**Лучше** или позже, если какой-то не хватает) и за сгенерированным лицом
с thispersondoesnotexist.com, когда вы жмёте 🎲.

| Что | Где |
|---|---|
| Лица и настройки | `~/Library/Application Support/Mirage` |
| Логи | `~/Library/Logs/Mirage` |

Чтобы начать с чистого листа, закройте Mirage и удалите первую папку.

## Классический интерфейс Deep-Live-Cam

Оригинальное окно Deep-Live-Cam никуда не делось и работает, включая то, чего
Mirage не делает (обработка фото и видеофайлов, сопоставление лиц):

```bash
make classic        # или: source venv/bin/activate && python run.py
```

Оригинальный README сохранён в [docs/upstream/README.md](docs/upstream/README.md).
